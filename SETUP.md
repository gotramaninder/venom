# VENOM setup

Please follow the simple guide in [README.md](README.md).

- First install: `1_SETUP_VENOM.bat`
- Daily use: `2_START_VENOM.bat`
- API keys: `3_API_SETUP.bat`
- Optional dashboard dependencies: `4_DASHBOARD_SETUP.bat`
- Optional phone access: `5_PHONE_SETUP.bat`

Do not move or rename the internal Python modules. Keep your `.env`, `data/`, and `outputs/` folders safe. They contain private settings and user records.
