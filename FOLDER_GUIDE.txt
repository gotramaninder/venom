VENOM - SIMPLE FOLDER GUIDE

Pehli baar:
  1_SETUP_VENOM.bat

Purane VENOM ka data lana ho:
  IMPORT_OLD_VENOM.bat

Roz chalana:
  2_START_VENOM.bat

API keys:
  3_API_SETUP.bat

Backup:
  BACKUP_VENOM.bat

Optional:
  4_DASHBOARD_SETUP.bat
  5_PHONE_SETUP.bat

BAAKI .py FILES ENGINE KE INTERNAL PARTS HAIN. UNHE MOVE, DELETE YA RENAME MAT KARNA.

data = clients, payments, leads, meetings, settings, chat history
logs = error / activity logs
outputs = generated files and uploaded media
static = VENOM HUD screen
.venv = Python environment (setup khud banata hai)
.env = private API keys (GitHub par kabhi upload mat karna)

Purana folder safe rahega. Importer existing data overwrite nahi karta.
